## New: optional Mac desktop control

Enable **Settings > Mac control** to let your coordinator work with apps and browser tabs you choose for a request.

- Discover installed/running apps and explicitly select a browser.
- List tabs and create a new tab in an existing window; select, navigate and close exact tabs.
- Read selected app windows and browser pages through Accessibility.
- Reuse known Gemini/Claude controls, with separate drafting and sending for owner-authorized tasks.
- Stop and disable control from Settings. Unknown actions are not retried automatically.

The macOS app bundles the verified Cua 0.38.0 driver. No separate lab app, driver setup or browser debugging is required. Accessibility and browser Automation permissions remain under your control.

This is an opt-in preview. Comet was exercised live in the lab; other Chromium adapters need compatibility validation. Safari and Firefox have discovery only. Accessibility can return incomplete content, and incomplete chat trees are refused. App/account permissions and Claude session-initiation rules still apply.

Packaged build, startup and driver-handshake checks are separate from live input validation on each user's Mac. Ad-hoc-signed updates can require permission reapproval. Windows and Linux retain their existing features; desktop control is macOS-only.
