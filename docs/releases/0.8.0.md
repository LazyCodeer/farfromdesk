# FarFromDesk 0.8.0

Hackathon release.

## Changes

- Adds an opt-in Meta-powered Brain to interpret owner messages, route work to connected sessions, and answer from saved task history. Greetings and clarification questions can receive short conversational replies.
- Tracks item ownership, codes, progress and replies. Status-only update requests contact the proven owning session without restarting work. Replaced or paused owners receive an explicit recovery choice.
- Handles a closed Codex input pipe without an unhandled crash or automatic retry.
- Improves routing and duplicate-notification handling, and keeps new proxy folders under the FarFromDesk home directory.
- Redesigns the Mac control and Brain settings cards. Accessibility and Screen Recording have separate status rows; Mac control has a stop control and scratch controls for a benign trial.
- Adds Meta Muse Voice Transcribe as an optional voice-note provider, with WAV conversion and an explicit option to reuse the Brain key. Meta appears first when choosing an API provider. Advanced local voice settings appear only under On this computer. Existing saved voice settings are preserved.

## Requirements and limitations

Meta Brain and voice require a configured Meta API account. Selecting a cloud feature sends the relevant conversation or audio data to that provider. Native app permissions remain controlled by macOS and the owner.

Mac control depends on the selected app exposing usable controls. Remote desktop from your phone is an early preview; full phone control is not ready yet.

This hackathon build is **ad-hoc signed and not notarized by Apple**.

On first open, macOS may say FarFromDesk can't be checked. Right-click (or Control-click) the app, choose **Open**, then **Open** again. If it is still blocked, open **System Settings**, then **Privacy & Security**, then **Open Anyway**. Depending on your macOS version, you may need to attempt to open the app once before Open Anyway appears. Confirm these prompts yourself only if you trust the download.

Accessibility, Screen Recording, Automation or external-drive access may need granting again after an update because the ad-hoc signing identity can change. Developer ID signing is planned for later; it is not included in this version.
