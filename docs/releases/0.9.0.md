# FarFromDesk 0.9.0

## Changes

- Adds a memory folder that every session reads. Plain Markdown files hold what to call you, your reply style, words and names you use, your preferences and project notes. The always-read files go with each message; the rest are opened only when a message needs them.
- On the first hello the Brain introduces itself and asks what to call you. What you tell it is saved to memory, announced on WhatsApp and can be taken back by replying "undo". Replies from sessions, quoted text and files never change your memory. Learning can be turned off.
- Adds collaboration.md, which says which platform or session handles which kind of work, for example planning with Codex and coding with Claude. The Brain and your proxy follow it when a task needs another session. A platform you name in a message always wins.
- The Brain now uses the Vercel AI SDK with memory tools, so understanding comes from the model rather than fixed word lists.
- Redesigns the desktop app with Items and Brain pages. Memory shows one card per file with editable lines, Collaboration rules, a size meter and a history of changes with Undo.
- Turning the Brain on now lets it send work to your connected Codex and Claude sessions, keep your item list and answer status questions. The separate permission switches are removed.

## Requirements and limitations

The Brain requires a configured Meta API account. When it is on, your message, recent conversation and the always-read memory files are sent to Meta. Keep keys and passwords out of memory files; obvious credentials are refused.

This build is **ad-hoc signed and not notarized by Apple**.

On first open, macOS may say FarFromDesk can't be checked. Right-click (or Control-click) the app, choose **Open**, then **Open** again. If it is still blocked, open **System Settings**, then **Privacy & Security**, then **Open Anyway**. Depending on your macOS version, you may need to attempt to open the app once before Open Anyway appears. Confirm these prompts yourself only if you trust the download.

Accessibility, Screen Recording, Automation or external-drive access may need granting again after an update because the ad-hoc signing identity can change.
