## What changed

- Choose WhatsApp or Telegram for phone control. Telegram uses a dedicated bot, a private-chat pairing link and local account confirmation. Switch messaging apps in Settings; Home shows a clear Disconnect action.
- Voice notes can use the on-device model or your own Deepgram/AssemblyAI API key. Optional fallback uses an already-downloaded local model. Cloud mode sends audio to the chosen provider and may incur that provider's charges.
- Updated Home, Settings, activity history and coordinator management. Coordinator names are prefilled and directly editable; workspace discovery avoids unnecessary protected-folder scans.
- Session-scoped `ffd` launchers and skills simplify replies and coordinator handoffs, with stable event IDs for retries. Envelopes are shorter and replies retain their original channel.
- Claude Desktop setup opens a prepared native chat. Confirm the folder and press Send on the Mac, then FarFromDesk verifies the session acknowledgment before connecting it. Native trust and account permissions remain in force.
- WhatsApp traffic is restricted to the owner's chat or registered owner-only groups, and selected-group routing avoids unwanted self-chat dispatches.

## Scope and limitations

Experimental browser and Mac Accessibility control are not included; their live trials remain unfinished in the local development build. This release does not enable new computer-control permissions.

Telegram Bot API chats are not end-to-end encrypted Secret Chats. Incoming Telegram files are limited to 20 MB and outgoing documents to 50 MB. Service terms and rate limits still apply. The configured computer must remain online. Not every provider account/platform combination has been live-tested; cloud voice tests use mocked provider responses.
