# Local email integration and review handoff

This checkout contains the email integration for **review**, not an installed build. The source was copied from the in-progress Local integration snapshot and includes its unrelated working changes. Carry only the email changes forward; do not replace that checkout wholesale. This work has not restarted, installed or modified either running app, contacted a real inbox, used real credentials, or sent real mail.

## Implemented

- Local-only desktop navigation, account configuration and disconnect, explicit Meta email-data consent, inbox, summaries, tone guidance, editable drafts and exact send review. Gmail presets are provided; custom hosts must use implicit TLS and resolve exclusively to public addresses. App-password availability varies with Google account and organization policy; OAuth and STARTTLS are unavailable. Saved means unverified, not connected.
- Local-only authenticated desktop HTTP routes reject session binding tokens and browser origins. The agent/model gets no send tool. After the panel's review, a separate native confirmation shows the saved envelope and body. The host binds its decision to the exact owner generation, account generation, revision and digest. Cancellation sends nothing; edits, revocation and replay fail closed. SMTP acceptance does not guarantee delivery, and an uncertain result is never retried automatically.
- A native Keychain broker holds an OS lock while running and until any synchronous credential operation finishes, including when its parent exits. The process wrapper uses stdin, waits for responses or process exit and does not expose provider errors. SQLite holds opaque slots and owner-only draft data, not passwords. At exclusive startup, interrupted claims become uncertain and ambiguous staged credentials remain protected until a later macOS boot, when they become eligible for cleanup. A synthetic temporary keychain exercises the broker without opening the login keychain.
- The IMAP parser returns bounded plain-text content only; attachments are counted and HTML-only content is unavailable. Message data is untrusted and the model has no tools. Replies require the source message digest to match a fresh read. The optional Meta writer is allowed only after the Local owner enables consent and Meta Brain is enabled. Revocation prevents further results but cannot retract content already sent to the provider.
- The network adapter rejects literal IP hosts, private, local, reserved and mixed DNS results, and supplies the validated address to the TLS connection while retaining hostname certificate checks. TLS only; no plaintext fallback.
