# Attribution and asset scope

The workflow was informed by https://github.com/upbrew-tech/svg-creator-skill (Apache-2.0). Its pinned source remains in the local SVG trial; this package uses an original bounded renderer instead of its hardcoded execution loop. Copy planning was informed by MIT-licensed Agency Agents and coreyhaines31/marketingskills.

The generated illustration library and cart drawing were prepared for this owner’s FarFromDesk prototype. Splice AI's icon is included solely for its own brand. Other brands use their own context and a text label; there is no grant of Splice trademark rights. Instagram and WhatsApp official packs are deliberately not redistributed here. Font notices accompany their files in assets/.

This skill and its local rendering code do not require a paid image API. Native sessions and selected Meta API usage remain subject to their own plans and pricing.
