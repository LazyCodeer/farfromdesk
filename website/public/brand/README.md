# FarFromDesk identity

The full name is FarFromDesk; FFD is the small icon/monogram. Three geometric letters rise away from a shared desk baseline. Use the full name alongside the mark on first introduction.

- ffd-icon.svg: app/web icon, 128-unit master, indigo tile.
- ffd-monogram.svg / ffd-monogram-white.svg: transparent single-color marks.
- farfromdesk-wordmark-dark.svg: light wordmark for dark surfaces.
- farfromdesk-wordmark-light.svg: dark wordmark for light surfaces.
- ffd-icon-1024.png: native icon source export.
- brand-overview.png: usage preview.

Palette: ink #171D36, indigo #AAB6FF, canvas #17181D, paper #F2F2F4.
Wordmark uses outlined Outfit Medium; font license in ../licenses. All SVG lettering is paths, so it requires no installed fonts. Leave clear space of at least one vertical letter stroke around the mark. Use the tile at 24px or larger, and prefer the wordmark at 160px or larger. The web header uses live accessible text in Outfit.

Created directly as vector artwork for the existing SVG website; no image-generation API used. Design brief: a simple, legible FFD monogram with ascending geometric letters, paired with the complete FarFromDesk name. Avoid superhero references and decorative detail.
