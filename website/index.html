GOOD QUESTIONS

Before you
step away.

What exactly is FarFromDesk?+

FarFromDesk is a local Mac app that connects WhatsApp to selected Codex and Claude coding sessions. A master session coordinates the work and sends replies back to your chosen WhatsApp conversation.

Does my Mac need to stay on?+

Yes. Your Mac, coding runtime and WhatsApp connection must remain available. FarFromDesk can optionally prevent idle sleep, but this does not override manual sleep, lid closure, shutdown or low-battery safeguards. Closed-lid use depends on your Mac’s supported configuration.

Can I use several coding sessions?+

Yes. Select the sessions you want your master to coordinate using the session list. Each session retains its original context and permissions. Quoting a session’s WhatsApp reply addresses that session directly.

Are voice notes processed locally?+

Transcription runs on your Mac using bundled speech tools in the packaged preview. Voice notes first travel through WhatsApp; the resulting text is sent to your coding session. Notes are limited to five minutes and 10 MiB. Permission decisions must be typed.

Can I approve an action from WhatsApp?+

Supported native permission requests can be approved or denied with a typed command when the integration’s trusted hooks are active. Approval is specific to that request, expires, and does not override native policy. Some actions still need attention in the coding app.

Is FarFromDesk ready to download?+

The app is currently a local preview. A public, signed and notarized installer has not been published. The release area below will link to a verified download when one is available. Windows and Linux apps are coming soon. Intel Mac support is not currently confirmed.

Is this an official WhatsApp, OpenAI or Anthropic app?+

No. FarFromDesk is an independent Codecy Labs product. It uses a linked-device integration for WhatsApp and native coding integrations. Compatibility can change with provider updates and account restrictions.
